# Коды ошибок отказоустойчивости

Библиотека создает структурированные ошибки с помощью пакета `errors`. Общие ошибки используют стандартные коды,
а предметные отказы стратегий имеют коды из пространства `resilience`.

## Предметные коды

Для обработки без строковых литералов используйте функции модуля `КодыОшибокОтказоустойчивости`.

| Функция | Код | Назначение |
| --- | --- | --- |
| `ПревышениеТаймаута()` | `resilience.timeout.exceeded` | Истекло время выполнения операции |
| `ОтклонениеПоОграничениюВызовов()` | `resilience.rate_limit.rejected` | Ограничитель не выдал разрешение на вызов |
| `ОтклонениеПоОграничениюПараллелизма()` | `resilience.parallelism.rejected` | Все слоты заняты, очередь ожидания заполнена |
| `ПревышениеОжиданияСлотаПараллелизма()` | `resilience.parallelism.wait_timeout` | Превышено время ожидания слота |
| `ОсвобождениеНезанятогоСлота()` | `resilience.parallelism.slot_not_acquired` | Освобождается незанятый слот |
| `ОтклонениеИзмененияОграниченийПараллелизма()` | `resilience.parallelism.reconfiguration_rejected` | Ограничения меняются при активных операциях |
| `РазомкнутыйПредохранитель()` | `resilience.circuit.open` | Предохранитель не допустил обычный или пробный вызов |
| `ОтменаОперации()` | `resilience.operation.cancelled` | Получен запрос отмены операции |

Предметные ошибки не дублируют данные контекстов обработчиков. Параметры таймаута, ограничения вызовов и ограничения
параллелизма доступны соответствующим обработчикам. Причина прерывания и состояние предохранителя отражаются в
сообщении ошибки.

## Стандартные коды

| Код | Источник в `resilience` |
| --- | --- |
| `argument.required` | Не передана обязательная стратегия |
| `argument.invalid_type` | Передан неподдерживаемый тип стратегии или операции |
| `argument.invalid_value` | Передано неподдерживаемое значение настройки или сочетание параметров |
| `argument.out_of_range` | Числовая настройка вне допустимого диапазона |

Ошибки пользовательской операции и пользовательских обработчиков библиотека повторно выбрасывает без замены их кода.
