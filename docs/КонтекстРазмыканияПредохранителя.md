# КонтекстРазмыканияПредохранителя

## Синтаксис:

```bsl
Новый КонтекстРазмыканияПредохранителя(
	<ПорогОшибок>,
	<КоличествоОшибокПодряд>,
	<ДлительностьРазмыкания>,
	<ДанныеОшибки>,
	<Состояние>,
	[<КоличествоВызововВОкне>],
	[<КоличествоОшибокВОкне>],
	[<ПроцентОшибок>],
	[<ПричинаРазмыкания>])
```

**Параметры:**

| Имя | Тип | Значение по умолчанию | Описание |
| -- | -- | -- | -- |
| ПорогОшибок | Число |  | Количество ошибок подряд до размыкания |
| КоличествоОшибокПодряд | Число |  | Текущее количество ошибок подряд |
| ДлительностьРазмыкания | Число |  | Длительность размыкания в миллисекундах |
| ДанныеОшибки | ИнформацияОбОшибке, Неопределено |  | Ошибка, вызвавшая размыкание. `Неопределено`, если размыкание произошло без ошибки операции |
| Состояние | Строка |  | Текущее состояние предохранителя |
| КоличествоВызововВОкне | Число | `0` | Необязательный. Количество завершенных вызовов в окне оценки |
| КоличествоОшибокВОкне | Число | `0` | Необязательный. Количество ошибок в окне оценки |
| ПроцентОшибок | Число | `0` | Необязательный. Процент ошибок в окне оценки |
| ПричинаРазмыкания | Строка | `ПричиныРазмыканияПредохранителя.ПоследовательныеОшибки` | Необязательный. Причина размыкания предохранителя, см. [ПричиныРазмыканияПредохранителя](ПричиныРазмыканияПредохранителя.md) |

## ПорогОшибок

**Синтаксис:**

```bsl
ПорогОшибок()
```

**Возвращаемое значение:**

Тип: Число.

**Описание:**

Возвращает порог ошибок подряд до размыкания.


## КоличествоОшибокПодряд


**Возвращаемое значение:**

Тип: Число.

**Описание:**

Возвращает текущее количество ошибок подряд.


## ДлительностьРазмыкания

**Синтаксис:**

```bsl
ДлительностьРазмыкания()
```

**Возвращаемое значение:**

Тип: Число.

**Описание:**

Возвращает длительность размыкания в миллисекундах.


## ДанныеОшибки

**Синтаксис:**

```bsl
ДанныеОшибки()
```

**Возвращаемое значение:**

Тип: ИнформацияОбОшибке, Неопределено.

**Описание:**

Возвращает ошибку, вызвавшую размыкание. Если предохранитель разомкнулся без текущей ошибки операции, например по проценту ошибок после успешного вызова, возвращает `Неопределено`.


## Состояние

**Синтаксис:**

```bsl
Состояние()
```

**Возвращаемое значение:**

Тип: Строка.

**Описание:**

Возвращает текущее состояние предохранителя. Возможные значения описаны в [СостоянияПредохранителя](СостоянияПредохранителя.md).


## КоличествоВызововВОкне

**Синтаксис:**

```bsl
КоличествоВызововВОкне()
```

**Возвращаемое значение:**

Тип: Число.

**Описание:**

Возвращает количество завершенных вызовов, которые участвовали в оконной оценке к моменту размыкания. Если оконный режим выключен или предохранитель повторно разомкнулся пробным вызовом, возвращает `0`.


## КоличествоОшибокВОкне

**Синтаксис:**

```bsl
КоличествоОшибокВОкне()
```

**Возвращаемое значение:**

Тип: Число.

**Описание:**

Возвращает количество ошибочных вызовов в окне оценки к моменту размыкания. Если оконный режим выключен или предохранитель повторно разомкнулся пробным вызовом, возвращает `0`.
