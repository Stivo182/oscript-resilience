# ПричиныРазмыканияПредохранителя

## Синтаксис:

```bsl
ПричиныРазмыканияПредохранителя.<Значение>
```

## Значения

[ПоследовательныеОшибки](#последовательныеошибки) </br>
[ПроцентОшибок](#процентошибок) </br>
[ПробныйВызов](#пробныйвызов)


## ПоследовательныеОшибки

**Синтаксис:**

```bsl
ПричиныРазмыканияПредохранителя.ПоследовательныеОшибки
```

**Тип значения:**

Строка.

**Описание:**

Предохранитель разомкнулся после серии ошибок подряд.


## ПроцентОшибок

**Синтаксис:**

```bsl
ПричиныРазмыканияПредохранителя.ПроцентОшибок
```

**Тип значения:**

Строка.

**Описание:**

Предохранитель разомкнулся по проценту ошибок в окне оценки.


## ПробныйВызов

**Синтаксис:**

```bsl
ПричиныРазмыканияПредохранителя.ПробныйВызов
```

**Тип значения:**

Строка.

**Описание:**

Предохранитель разомкнулся повторно после ошибки пробного вызова.
