## УстановитьСрок

**Синтаксис:**

```bsl
УстановитьСрок(<Длительность>)
```

**Параметры:**

| Имя | Тип | Описание |
| -- | -- | -- |
| Длительность | Число | Длительность срока от текущего момента в миллисекундах |

**Описание:**

Устанавливает срок операции. Значение `0` означает немедленное истечение. Повторная установка до прерывания
заменяет срок, отсчитывая новую длительность от текущего момента. После прерывания сигнал сохраняет состояние
первого прерывания и новый срок не устанавливается.

**Исключения:**

| Код | Описание |
| -- | -- |
| `argument.out_of_range` | Длительность меньше нуля |


## ЗапроситьПрерывание

**Синтаксис:**

```bsl
ЗапроситьПрерывание(<ПричинаПрерывания>)
```

**Параметры:**

| Имя | Тип | Значение по умолчанию | Описание |
| -- | -- | -- | -- |
| ПричинаПрерывания | Строка, Неопределено | `Неопределено` | Текст причины прерывания |

**Описание:**

Запрашивает кооперативное прерывание операции. Повторные вызовы ничего не меняют.


## ПрерываниеЗапрошено

**Синтаксис:**

```bsl
ПрерываниеЗапрошено()
```

**Возвращаемое значение:**

Тип: Булево.

**Описание:**

Возвращает `Истина`, если прерывание уже было запрошено или установленный срок истек.


## ПричинаПрерывания

**Синтаксис:**

```bsl
ПричинаПрерывания()
```

**Возвращаемое значение:**

Тип: Строка, Неопределено.

**Описание:**

Возвращает причину прерывания, переданную при вызове `ЗапроситьПрерывание(...)`. После истечения срока возвращает
строку вида `Истек срок операции: <N> мс.`.


## ОсталосьВремени

**Синтаксис:**

```bsl
ОсталосьВремени()
```

**Возвращаемое значение:**

Тип: Число, Неопределено.

**Описание:**

Возвращает оставшееся до истечения срока время в миллисекундах, но не меньше `0`. Если срок не установлен,
возвращает `Неопределено`.


## ПроверитьПрерывание

**Синтаксис:**

```bsl
ПроверитьПрерывание()
```

**Описание:**

Если прерывание не запрошено и срок не истек, метод ничего не делает. При явной отмене вызывается исключение с кодом
`resilience.operation.cancelled` и причиной прерывания или со стандартным текстом `Выполнение операции отменено.`.
После истечения срока вызывается исключение с кодом `resilience.operation.deadline_exceeded`.

**Исключения:**

| Код | Описание |
| -- | -- |
| `resilience.operation.cancelled` | Запрошена отмена операции |
| `resilience.operation.deadline_exceeded` | Истек срок операции |

> [!NOTE]
> `СигналПрерыванияОперации` не останавливает уже выполняющийся пользовательский код принудительно. Стратегии могут проверять сигнал, например перед запуском следующего шага или во время ожидания.
>
> Пользовательский код тоже может работать с этим объектом напрямую. Если у операции есть доступ к тому же экземпляру `СигналПрерыванияОперации`, она может периодически вызывать `ПроверитьПрерывание()` или проверять `ПрерываниеЗапрошено()` и завершаться кооперативно.
>
> Один и тот же экземпляр сигнала является одноразовым: после явной отмены или истечения срока метод
> `ПрерываниеЗапрошено()` возвращает `Истина`, а `ПроверитьПрерывание()` выбрасывает исключение. Не переиспользуйте
> уже прерванный сигнал для новой независимой операции.
