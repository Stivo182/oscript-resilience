# ТипыОграниченияВызовов

## Синтаксис:

```bsl
ТипыОграниченияВызовов.<Значение>
```

## Значения

[ФиксированноеОкно](#фиксированноеокно) (`Fixed Window`) </br>
[РавномерноеРаспределение](#равномерноераспределение) (`Smooth Rate Limiter`)


## ФиксированноеОкно

**Синтаксис:**

```bsl
ТипыОграниченияВызовов.ФиксированноеОкно
```

**Тип значения:**

Строка.

**Описание:**

Ограничивает количество вызовов внутри фиксированного интервала. Это режим по умолчанию.


## РавномерноеРаспределение

**Синтаксис:**

```bsl
ТипыОграниченияВызовов.РавномерноеРаспределение
```

**Тип значения:**

Строка.

**Описание:**

Распределяет разрешения равномерно по интервалу. Например, лимит `2` за `120` мс выдает разрешение примерно каждые `60` мс.

Равномерное распределение использует миллисекундную дискретность времени. Минимальный интервал между разрешениями — `1` мс. Если лимит требует чаще одного разрешения в миллисекунду, режим будет ограничивать консервативнее заданного лимита. Для таких сценариев используйте фиксированное окно или увеличьте интервал лимита.

По поведению режим близок к алгоритму `Leaky Bucket`.
