# Примеры

В каталоге `samples` собраны небольшие сценарии, которые показывают библиотеку в действии.
Каждый пример можно запускать отдельно и использовать как отправную точку для собственных экспериментов.

## Как запускать

Из корня репозитория:

```bash
oscript samples/ПримерОтказоустойчивости.os
```

По тому же шаблону можно запускать любой другой файл из каталога `samples`.

## С чего начать

Если открываешь библиотеку впервые, лучше идти от коротких сценариев к составным:

- [ПримерСтратегииЗапасногоСценария.os](ПримерСтратегииЗапасногоСценария.os) показывает самый простой запасной результат вместо ошибки.
- [ПримерСтратегииПовтора.os](ПримерСтратегииПовтора.os) показывает повтор операции, которая сначала возвращает промежуточный результат.
- [ПримерСтратегииТаймаута.os](ПримерСтратегииТаймаута.os) показывает ограничение времени выполнения.
- [ПримерОтказоустойчивости.os](ПримерОтказоустойчивости.os) показывает несколько стратегий в одном пайплайне.

## Примеры по стратегиям

| Стратегия | Что показывает | Файлы |
| --- | --- | --- |
| `ЗапаснойСценарий` | Резервный результат вместо ошибки и условие, которое разрешает запасной сценарий только для выбранных ошибок. | [Базовый пример](ПримерСтратегииЗапасногоСценария.os)<br>[С условием](ПримерСтратегииЗапасногоСценарияСУсловием.os) |
| `Повтор` | Повтор проверки, пока сервис возвращает промежуточный результат. | [Пример повтора](ПримерСтратегииПовтора.os) |
| `Предохранитель` | Размыкание после ошибок, оценка процента ошибок в окне и закрытие после нескольких успешных пробных вызовов. | [Базовый пример](ПримерСтратегииПредохранителя.os)<br>[Оконная оценка](ПримерСтратегииПредохранителяОконнаяОценка.os)<br>[Пробные вызовы](ПримерСтратегииПредохранителяПробныеВызовы.os) |
| `ОграничениеПараллелизма` | Ограничение числа одновременно выполняющихся операций, очередь ожидания и максимальное ожидание свободного слота. | [Базовый пример](ПримерСтратегииОграниченияПараллелизма.os)<br>[Ожидание слота](ПримерСтратегииОграниченияПараллелизмаОжиданиеСлота.os) |
| `Таймаут` | Базовое ограничение времени ожидания и кооперативное завершение операции через общий `СигналПрерыванияОперации`. | [Базовый пример](ПримерСтратегииТаймаута.os)<br>[С сигналом прерывания](ПримерСтратегииТаймаутаССигналомПрерывания.os) |
| `ОграничениеВызовов` | Лимит вызовов в интервале, обработчик превышения лимита и равномерное распределение запросов. | [Базовый пример](ПримерСтратегииОграниченияВызовов.os)<br>[Равномерное распределение](ПримерСтратегииОграниченияВызововСРавномернымРаспределением.os) |

## Примеры пайплайна и API

- [ПримерОтказоустойчивости.os](ПримерОтказоустойчивости.os) показывает, как `Повтор`, `Предохранитель` и `ЗапаснойСценарий` работают вместе: первый запуск возвращает резервный результат, а после ожидания следующий вызов завершается успешно.
- [ПримерПайплайнаИзГотовыхСтратегий.os](ПримерПайплайнаИзГотовыхСтратегий.os) показывает сборку пайплайна из заранее настроенных объектов стратегий.
- [ПримерАсинхронногоЗапуска.os](ПримерАсинхронногоЗапуска.os) показывает `ЗапуститьАсинх()` и получение результата через `Получить()`.
- [ПримерАсинхроннойОбработкиОшибки.os](ПримерАсинхроннойОбработкиОшибки.os) показывает обработку ошибки асинхронной операции через `Поймать()`.
- [ПримерЛямбдаОперации.os](ПримерЛямбдаОперации.os) показывает операцию, заданную лямбда-выражением.
- [ПримерЛямбдаОбработчика.os](ПримерЛямбдаОбработчика.os) показывает обработчик стратегии, заданный лямбда-выражением.
- [ПримерКастомнойСтратегии.os](ПримерКастомнойСтратегии.os) показывает подключение собственной стратегии через `ДобавитьСтратегию(...)`.

## Вспомогательные классы

- [Классы/НестабильныйСервис.os](Классы/НестабильныйСервис.os) имитирует сервис, который некоторое количество раз завершается ошибкой, а затем начинает отвечать успешно.
- [Классы/МедленныйСервис.os](Классы/МедленныйСервис.os) имитирует сервис с искусственной задержкой, удобный для примеров со стратегией таймаута.
- [Классы/ПрерываемыйСервис.os](Классы/ПрерываемыйСервис.os) показывает кооперативное прерывание длительной операции через общий `СигналПрерыванияОперации`.
- [Классы/СервисПроверкиГотовности.os](Классы/СервисПроверкиГотовности.os) возвращает промежуточный результат `НЕ ГОТОВО`, чтобы показать повтор по результату, а не только по исключению.
- [Классы/ПрефикснаяСтратегия.os](Классы/ПрефикснаяСтратегия.os) показывает минимальную пользовательскую стратегию с использованием `АдаптерОперацииОтказоустойчивости`.
